# Meditaire — 국시(KMLE) 연관어 솔리테어

*Solitaire Associations Journey* 방식으로, **같은 주제의 키워드 카드를 모아 주제 카드를 완성하는** 국시 공부용 솔리테어 웹 앱입니다.
앱스토어 없이 아이폰·아이패드 Safari에서 **홈 화면에 추가**하면 앱처럼 전체 화면으로, 오프라인에서도 돌아갑니다.

```
 C (덱)        [펼친 카드들]   [덱 20]
 A (주제 칸)   [CML 0/5] [  ] [  ] [  ]
 B (펼침 칸)   [BCR-ABL] [▒] [▒] [▒]
                         [▒] [▒] [보르테조밉]
                         [IVIG]
```

## 플레이 방법

1. **C (덱)** — 탭하면 1장씩 펼쳐집니다. 다 넘기면 ↻ 로 처음부터 다시 돌려요.
2. **A (주제 칸, 4~5칸)** — 주제 카드(노란 카드)를 올리는 곳. 주제 카드 **오른쪽 위 숫자**가 그 주제에 딸린 키워드 카드 수이고, 다른 곳에는 표시되지 않습니다.
   키워드 카드를 맞는 주제 위로 다 모으면 주제가 완성되어 칸이 비워집니다.
3. **B (펼침 칸, A와 같은 칸 수)** — 시작할 때 카드가 깔려 있고 맨 윗장만 앞면. **같은 주제 카드끼리만** 겹쳐 쌓을 수 있고, 빈 칸에는 아무 카드나 놓을 수 있습니다. 위 카드를 치우면 아래 카드가 뒤집혀요.
4. 카드를 **탭**하면 갈 수 있는 곳으로 자동 이동, **끌어서** 원하는 곳에 놓을 수도 있습니다.
5. 모든 주제를 완성하면 클리어. 결과 화면에서 이번 판의 **주제별 키워드 전체**를 복습할 수 있어요.

설정: 칸 수(자동/4/5), 난이도(한 판의 주제 수 = 칸 수 + 2/3/5). 되돌리기·힌트·진행 자동 저장·오프라인 지원.

기본 팩 (키워드 위주, 검사·약은 정말 특징적인 것만):
**혈액종양**(17주제) · **내분비**(15주제) · **소화기**(14주제) · **순환기**(13주제) · 전체 섞기

## 아이폰에 설치하기 (무료, 5분)

1. 이 저장소를 GitHub Pages로 공개: 저장소 **Settings → Pages → Branch** 에서 배포할 브랜치와 `/ (root)` 선택 → 저장
   - 무료 플랜의 GitHub Pages는 **공개 저장소**에서만 됩니다. 비공개로 두고 싶으면 [Netlify Drop](https://app.netlify.com/drop)이나 Cloudflare Pages에 폴더를 드래그해서 올려도 됩니다.
2. 아이폰 Safari로 `https://<아이디>.github.io/<저장소>/` 접속
3. 공유 버튼 → **홈 화면에 추가** → 이제 아이콘으로 실행, 한 번 열어 두면 오프라인(열람실·병원)에서도 동작

> 홈 화면에 추가한 웹 앱은 Safari 일반 탭과 달리 7일 미사용 시 저장 데이터가 지워지는 정책에서 제외되므로, 내 카드팩과 기록이 유지됩니다.

## 내 카드팩 만들기 (LLM 파이프라인)

메뉴 → **내 카드팩 추가** → **카드 생성 프롬프트 복사** → ChatGPT/Claude에 서머리 노트와 함께 붙여넣기 → 받은 JSON을 붙여넣고 저장.

```json
{
  "topics": [
    { "name": "거대적혈모구빈혈", "cards": ["비타민 B12 결핍", "엽산 결핍", "위절제술", "채식주의자", "손발 저림", "MCV > 100"] },
    { "name": "만성 골수성 백혈병 (CML)", "cards": ["BCR-ABL", "필라델피아 염색체 t(9;22)", "이마티닙 (TKI)", "거대 비장"] }
  ]
}
```

- 주제당 키워드 **3~8장** (8장 넘으면 앞 8장만 사용, 3장 미만인 주제는 제외)
- 키워드 문구는 팩 전체에서 중복되면 안 됩니다 (한 키워드는 한 주제에만)
- 주제는 최소 4개, 한 판에 칸 수 + 2~5개를 뽑아 쓰므로 **10개 이상** 권장
- **LLM이 만든 내용은 틀릴 수 있으니 한 번은 교과서와 대조**하세요. 기본 팩을 고치거나 늘리려면 `packs.js`를 직접 편집하면 됩니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (HTML/CSS/JS 한 파일, 빌드 도구 없음) |
| `packs.js` | 기본 카드팩 데이터 (주제 → 키워드 목록) |
| `sw.js` | 오프라인 캐시 서비스 워커 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 아이콘·이름 |

로컬에서 보기: `python3 -m http.server` 후 `http://localhost:8000` (파일을 더블클릭해 열어도 게임은 되지만 오프라인 캐시는 http(s)에서만 동작)

## 조사 정리: 현실적으로 만들 수 있을까?

### 결론
**"앱스토어 출시"는 선택 사항이고, 게임 자체는 지금 이 저장소처럼 웹 앱(PWA)으로 충분히 만들 수 있습니다.**
이 장르(카드 몇십 장, 탭, 애니메이션)는 게임 엔진이 필요 없는 수준이라 HTML 한 파일로 구현 가능하고, 본인 공부용이면 PWA가 가장 현실적입니다.

### 선택지 비교

| 방법 | 비용 | 난이도 | 게임 UI | 오프라인 | 남에게 배포 |
|---|---|---|---|---|---|
| **웹 앱 + 홈 화면 추가 (PWA)** ← 추천 | 무료 | 낮음 | ◎ 자유 | ○ | 링크 공유 |
| 단축어(Shortcuts) | 무료 | 낮음 | ✕ 메뉴/알림창 수준 | ○ | 단축어 링크 |
| Anki 커스텀 카드 | 무료(iOS 앱 유료) | 중간 | △ 카드 넘기기만 | ○ | 덱 파일 |
| TestFlight (앱스토어 전 단계) | 연 $99 | 중~높음 | ◎ | ◎ | 초대 링크, 최대 1만 명 |
| 앱스토어 정식 출시 | 연 $99 | 높음 | ◎ | ◎ | 누구나 |

### 앱스토어가 어려운 이유 (실제로는 "돈 + 심사 + Mac")
- **Apple Developer Program 연회비 $99** (국내 약 13만 원/년) — 끊기면 앱 내려감
- **빌드 환경**: 원칙적으로 Mac + Xcode 필요. React Native(Expo)의 클라우드 빌드(EAS)를 쓰면 Mac 없이도 빌드·제출은 가능
- **심사 가이드라인 4.2 (최소 기능)**: 웹사이트를 껍데기만 앱으로 감싼 경우 반려되기 쉬움 → 네이티브 기능(위젯, 알림 등)을 더해야 하는 경우가 많음
- **저작권·상표**: 국시원 기출 문항을 그대로 옮기면 안 되고(본인 노트 기반으로 재구성), 원작 게임의 이름·아트·UI를 베끼면 안 됨. "태그가 겹치면 이어지는 카드 게임"이라는 **규칙 자체는** 문제되지 않지만 외형은 독자적으로 만들어야 함
- 개인정보처리방침 URL, 스크린샷, 연령 등급 설문 등 메타데이터 준비

→ 먼저 PWA로 만들어 몇 주 써 보고, 동기들 반응이 좋으면 그때 같은 코드를 Capacitor로 감싸 앱스토어에 내는 순서가 효율적입니다 (이 코드는 거의 그대로 재사용 가능).

### 단축어로는 어디까지?
- 가능: "목록에서 선택"으로 **4지선다 연관어 퀴즈**, 사전(Dictionary) 동작에 카드 데이터 저장, 매일 알림으로 1문제 출제
- 불가능: 카드 배치·탭·애니메이션 같은 **게임 화면** — 단축어는 메뉴와 알림창만 띄울 수 있음
- 현실적 활용: 단축어는 **이 웹 앱을 여는 런처**나 **자투리 시간 한 문제 퀴즈**로 보조 역할
