# Meditaire — 국시(KMLE) 연관어 솔리테어

*Solitaire Associations Journey* 방식으로, 단계별 이동 제한 안에서, **같은 주제의 키워드 카드를 모아 주제 카드를 완성하는** 국시 공부용 솔리테어 웹 앱입니다.
앱스토어 없이 아이폰·아이패드 Safari에서 **홈 화면에 추가**하면 앱처럼 전체 화면으로, 오프라인에서도 돌아갑니다.

```
 C (덱)        [펼친 카드들]   [덱 20]
 A (주제 칸)   [CML 0/5] [  ] [  ] [  ]
 B (펼침 칸)   [BCR-ABL] [▒] [▒] [▒]
                         [▒] [▒] [보르테조밉]
                         [IVIG]
```

## 플레이 방법

1. **C (덱)** — 탭하면 1장씩 펼쳐집니다. 다 넘기면 ↻ 로 처음부터 다시 돌려요.
2. **A (주제 칸)** — 주제 카드(노란 카드)를 올리는 곳. 주제 카드 **오른쪽 위 숫자**가 그 주제의 키워드 카드 수입니다.
   키워드가 올라가면 **마지막에 올린 키워드가 크게**, 주제 이름은 위에 작게 보여요. 다 모으면 주제가 완성되어 칸이 비워집니다.
3. **B (펼침 칸)** — 시작할 때 카드가 깔려 있고 맨 윗장만 앞면.
   - 같은 주제의 키워드끼리만 쌓을 수 있고, 쌓인 카드는 **한 뭉치로만** 움직입니다.
   - 주제 카드는 **빈 칸**이나 **같은 주제 키워드 뭉치 위**에만 놓을 수 있고, B에서는 주제 카드 위에 아무것도 올릴 수 없습니다 (키워드를 주제 카드 위에 모으는 건 A에서만).
   - 주제 카드를 얹은 뭉치는 통째로 A로 보낼 수 있어요.
4. 카드는 **끌어서 놓아야만** 움직입니다. 카드를 탭해도 아무 일도 일어나지 않아요 (덱 펼치기만 탭).

### 단계
- 단계마다 **정해진 이동 횟수** 안에 모든 주제를 완성해야 클리어 → 다음 단계로. 덱 넘기기도 1번으로 셉니다.
- 난이도는 단계마다 무작위: **쉬움 25% · 보통 55% · 어려움 20%**. 쉬움·보통은 4칸, 어려움은 5칸.
- 이동 제한은 매 판 자동 플레이로 실제로 클리어 가능한지 확인한 뒤, 그 이동 수에 여유를 더해 정해집니다 (쉬움 ×1.4, 보통 ×1.25, 어려움 ×1.1, +5). 너무 쉽거나 어려우면 `index.html`의 `DIFFS`에서 `slack` 값을 조절하세요.
- 실패하면 같은 판을 다시 도전할 수 있어요. 결과 화면에서 이번 판 주제별 키워드 전체를 복습할 수 있습니다.

### 코인
- 단계를 클리어하면 **남은 이동 × 5 코인** (예: 60번 중 40번 만에 끝내면 20 × 5 = 100코인).
- **되돌리기 1회 = 600코인** (게임 중 · 막혔을 때).
- **이동 +10 = 2500코인** — 이동을 다 썼는데 못 끝냈을 때 결과 화면에서 구매.
- 힌트는 무료.

### 하트
- 최대 5개. 이동을 다 쓰고(또는 더 둘 곳이 없어) **포기하면 하트 −1**. 진행 중인 단계를 "처음부터"로 다시 하거나 트랙을 바꿔 버리는 것도 포기로 쳐요.
- 하트가 없으면 새 단계를 시작할 수 없어요. 채우는 방법:
  - **30분**마다 1개씩 자동 회복
  - **하트 충전 퀴즈**: 10초 안에 답하는 4지선다, **5문제 연속** 정답이면 하트 +1 (틀리거나 시간 초과면 연속 기록 초기화). 문제는 선택한 트랙의 카드 데이터에서 나와요 — "이 주제의 키워드는?" / "이 키워드는 어느 주제?"
- 카드를 끌고 가는 동안에는 맞는 자리인지 표시되지 않아요. 직접 놓아 봐야 붙는지 알 수 있습니다.
- 카드가 주제 칸에 붙을 때 금빛으로 번쩍이며 "착" 소리가 나고, 주제를 완성하면 짧은 차임이 울려요 (메뉴에서 효과음 끄기 가능 · 아이폰 무음 모드에서는 안 들릴 수 있음). 웹앱은 아이폰에서 진동을 낼 수 없어서 효과음으로 대신합니다.

### 출석 (연속 출석 · 달력)
- 그날 **한 판을 끝내면**(클리어 또는 포기 확정) 출석. 앱을 열기만 하는 건 출석이 아니에요.
- 메뉴와 게임 화면 위쪽에 🔥 연속 출석일이 보이고, 메뉴 › **📅 달력**에서 월별로 출석한 날(주황색)과 그날 클리어한 판 수를 볼 수 있어요. 최장 연속 · 총 출석일도 표시.
- 날짜는 기기 시간 기준 자정에 바뀌어요.
- **❄️ 연속 출석 보호권** (🪙1,000, 최대 2개 보유): 출석을 빠뜨린 날이 있으면 다음에 앱을 열 때 자동으로 쓰여 연속을 지켜줘요. 빠진 날이 보유 개수보다 많으면 어차피 끊기므로 쓰지 않고 남겨 둬요. 달력에서 구매.
- **🔧 연속 출석 수리** (🪙1,500): 어제 하루를 빠뜨려 연속이 끊겼다면, 오늘 안에만 메뉴나 달력에서 복구할 수 있어요.
- 보호권 · 수리로 메운 날(달력의 파란 · 보라 칸)은 연속을 이어 주지만 연속 일수에 더해지지는 않아요 (듀오링고와 같음).

### 미션
- **일일 미션 3개**(각 🪙50) · **주간 미션 3개**(각 🪙500, 월요일에 바뀜). 완료하면 메뉴 › 🎯 미션에서 **받기**를 눌러 코인을 받아요 (받을 게 있으면 빨간 점).
- 미션은 날짜로 정해져서 앱을 다시 열어도 바뀌지 않아요.
- 일일 후보: 단계 N판 클리어 · 주제 N개 완성 · 키워드 N장 주제 칸에 올리기 · 되돌리기 없이 클리어 · 한 번도 잘못 놓지 않고 클리어 · 이동 N번 이상 남기고 클리어 · 퀴즈 N문제 맞히기 · 오늘의 과목 주제 N개 완성
- 주간 후보: N일 출석 · 단계 N판 클리어 · 주제 N개 완성 · 잘못 놓지 않고 N판 클리어 · 퀴즈 N문제 맞히기
- 퀴즈는 하트가 가득해도 연습으로 풀 수 있어요 (미션 진행).

### 헷갈린 주제 복습
- 카드를 **다른 주제의 카드 위**(B의 다른 주제 뭉치나 A의 다른 주제 칸)에 놓으려 하면, 게임 중에는 아무 표시 없이 **두 주제 모두 +1**로 기록돼요. 예: 이마티닙을 견갑난산에 놓으면 만성 골수성 백혈병 +1, 임신성 당뇨병 +1.
- 점수 · 이동 횟수 · 코인에는 전혀 영향이 없어요.
- 판이 끝나면 결과 화면 맨 위에 **많이 헷갈린 주제 순**으로 키워드와 함께 보여줘요. 메뉴에는 지금까지 누적으로 가장 헷갈린 주제가 표시돼요.

## 기록 백업 (내보내기 / 가져오기)
Safari 탭과 홈 화면 웹앱은 저장 공간이 따로라 기록이 공유되지 않아요. 옮기려면:
1. 기록이 있는 쪽에서 메뉴 → **📤 내보내기** → 코드 복사
2. 옮길 쪽에서 메뉴 → **📥 가져오기** → 붙여넣기 (그쪽 기록은 덮어써짐)

단계 · 코인 · 하트 · 진행 중인 판 · 내 카드팩 · 헷갈린 주제 기록이 모두 옮겨져요 (진행 중인 판의 되돌리기 기록만 제외). 기기 변경이나 웹앱 삭제에 대비해 가끔 코드를 메모 앱에 저장해 두세요.

### 트랙
기본은 모든 과목이 섞여 나오고, 메뉴의 **연습할 트랙**에서 특정 과목만 골라 연습할 수 있습니다 (여러 개 선택 가능).

기본 트랙 (키워드 위주, 검사·약은 정말 특징적인 것만):
13개 과목 · 188주제 · 키워드 1,312장 (주제당 평균 7장, 최대 10장)

| 트랙 | 주제 수 | 트랙 | 주제 수 |
|---|---|---|---|
| 혈액종양 | 18 | 소아청소년 | 16 |
| 내분비 | 15 | 산부인과 | 15 |
| 소화기 | 14 | 정형외과 (류마티스 포함) | 16 |
| 순환기 | 13 | 피부 | 15 |
| 호흡기 | 14 | 이비인후 | 15 |
| 신장 | 13 | 감염 | 12 |
| 비뇨기 | 12 | | |

**한 판에 나오는 키워드**: 주제마다 데이터베이스의 키워드 중 **4~8장이 무작위로** 뽑혀요 (데이터가 적은 주제는 가진 만큼). 같은 주제라도 판마다 다른 키워드가 나오고, 넉넉한 주제는 8장까지 나옵니다.

**겹치는 키워드**: 데이터베이스에서는 한 키워드가 여러 주제에 들어가도 됩니다 (예: `BCR-ABL`은 CML과 Precursor B-cell ALL 둘 다). 대신 **키워드가 하나라도 겹치는 주제끼리는 같은 판에 나오지 않아요** — CML이 뽑히면 그 판에는 Precursor B-cell ALL이 안 나옵니다.

카드 내용은 교과서에 정착된 고전적 고빈도 사실만 담았고, 개정이 잦은 세부 수치·항생제 요법은 넣지 않았습니다. 그래도 사람이 검토한 자료가 아니므로 본인 교재와 한 번 대조해 주세요.

## 과목(카드 데이터) 추가·수정하기

카드 데이터는 `data/` 폴더에 과목별 파일로 나뉘어 있습니다.

```
data/tracks.js   ← 과목 파일 목록
data/heme.js     ← 혈액종양
data/endo.js     ← 내분비
data/gi.js       ← 소화기
data/cardio.js   ← 순환기
data/resp.js     ← 호흡기        data/peds.js   ← 소아청소년
data/neph.js     ← 신장          data/obgy.js   ← 산부인과
data/uro.js      ← 비뇨기        data/ortho.js  ← 정형외과
data/infect.js   ← 감염          data/derm.js   ← 피부
data/ent.js      ← 이비인후
```

**새 과목 추가** (예: 근골격): `data/msk.js`를 만들고 `data/tracks.js` 목록에 `'msk.js'`를 한 줄 추가하면 됩니다. GitHub 웹에서 바로 편집해도 돼요.

```js
// data/msk.js
(window.MEDITAIRE_TRACKS = window.MEDITAIRE_TRACKS || []).push({
  "id": "msk",
  "name": "근골격",
  "subject": "정형외과 · 류마티스",
  "topics": [
    { "name": "류마티스 관절염", "cards": ["손 작은 관절 대칭성", "아침 강직 1시간 이상", "항CCP 항체", "메토트렉세이트"] }
  ]
});
```

- 주제당 키워드 **3~12장** (넉넉할수록 판마다 다양하게 나옴).
- 여러 주제에 해당하는 키워드는 **완전히 같은 문구로** 각 주제에 넣으세요 (`비장비대 O`처럼). 같은 문구면 그 주제들이 같은 판에 함께 나오지 않아요. `비장비대`와 `비장비대 O`처럼 문구가 조금이라도 다르면 다른 키워드로 취급돼 같은 판에 나올 수 있으니 주의.
- 여러 질환에 두루 해당하는 막연한 키워드(`MRI`, `고혈압`, `대증치료` 등)는 피하고, 그 주제에만 맞게 구체적으로 쓰세요.
- 수정 후 앱을 열면 바로 반영됩니다 (온라인이면 항상 서버의 최신 파일을 먼저 받고, 오프라인일 때만 저장된 사본을 씀).

## 아이폰에 설치하기 (무료, 5분)

1. 이 저장소를 GitHub Pages로 공개: 저장소 **Settings → Pages → Branch** 에서 배포할 브랜치와 `/ (root)` 선택 → 저장
   - 무료 플랜의 GitHub Pages는 **공개 저장소**에서만 됩니다. 비공개로 두고 싶으면 [Netlify Drop](https://app.netlify.com/drop)이나 Cloudflare Pages에 폴더를 드래그해서 올려도 됩니다.
2. 아이폰 Safari로 `https://<아이디>.github.io/<저장소>/` 접속
3. 공유 버튼 → **홈 화면에 추가** → 이제 아이콘으로 실행, 한 번 열어 두면 오프라인(열람실·병원)에서도 동작

> 홈 화면에 추가한 웹 앱은 Safari 일반 탭과 달리 7일 미사용 시 저장 데이터가 지워지는 정책에서 제외되므로, 내 카드팩과 기록이 유지됩니다.

## 내 카드팩 만들기 (LLM 파이프라인)

파일을 직접 고치지 않고 앱 안에서 추가할 수도 있습니다 (그 기기에만 저장). 메뉴 → **내 카드팩 추가** → **카드 생성 프롬프트 복사** → ChatGPT/Claude에 서머리 노트와 함께 붙여넣기 → 받은 JSON을 붙여넣고 저장.

```json
{
  "topics": [
    { "name": "거대적혈모구빈혈", "cards": ["비타민 B12 결핍", "엽산 결핍", "위절제술", "채식주의자", "손발 저림", "MCV > 100"] },
    { "name": "만성 골수성 백혈병 (CML)", "cards": ["BCR-ABL", "필라델피아 염색체 t(9;22)", "이마티닙 (TKI)", "거대 비장"] }
  ]
}
```

- 주제당 키워드 **3~12장** (12장 넘으면 앞 12장만 사용, 3장 미만인 주제는 제외)
- 여러 주제에 해당하는 키워드는 같은 문구로 여러 주제에 넣어도 돼요 (그 주제들은 같은 판에 함께 안 나옴)
- 저장한 팩은 **트랙**으로 추가됩니다. 주제는 최소 4개, 한 판에 6~9개를 뽑아 쓰므로 **10개 이상** 권장
- **LLM이 만든 내용은 틀릴 수 있으니 한 번은 교과서와 대조**하세요. 받은 JSON의 topics를 그대로 `data/새과목.js`에 넣으면 모든 기기에서 쓰는 기본 트랙이 됩니다.

## 조사 정리: 현실적으로 만들 수 있을까?

### 결론
**"앱스토어 출시"는 선택 사항이고, 게임 자체는 지금 이 저장소처럼 웹 앱(PWA)으로 충분히 만들 수 있습니다.**
이 장르(카드 몇십 장, 탭, 애니메이션)는 게임 엔진이 필요 없는 수준이라 HTML 한 파일로 구현 가능하고, 본인 공부용이면 PWA가 가장 현실적입니다.

### 선택지 비교

| 방법 | 비용 | 난이도 | 게임 UI | 오프라인 | 남에게 배포 |
|---|---|---|---|---|---|
| **웹 앱 + 홈 화면 추가 (PWA)** ← 추천 | 무료 | 낮음 | ◎ 자유 | ○ | 링크 공유 |
| 단축어(Shortcuts) | 무료 | 낮음 | ✕ 메뉴/알림창 수준 | ○ | 단축어 링크 |
| Anki 커스텀 카드 | 무료(iOS 앱 유료) | 중간 | △ 카드 넘기기만 | ○ | 덱 파일 |
| TestFlight (앱스토어 전 단계) | 연 $99 | 중~높음 | ◎ | ◎ | 초대 링크, 최대 1만 명 |
| 앱스토어 정식 출시 | 연 $99 | 높음 | ◎ | ◎ | 누구나 |

### 앱스토어가 어려운 이유 (실제로는 "돈 + 심사 + Mac")
- **Apple Developer Program 연회비 $99** (국내 약 13만 원/년) — 끊기면 앱 내려감
- **빌드 환경**: 원칙적으로 Mac + Xcode 필요. React Native(Expo)의 클라우드 빌드(EAS)를 쓰면 Mac 없이도 빌드·제출은 가능
- **심사 가이드라인 4.2 (최소 기능)**: 웹사이트를 껍데기만 앱으로 감싼 경우 반려되기 쉬움 → 네이티브 기능(위젯, 알림 등)을 더해야 하는 경우가 많음
- **저작권·상표**: 국시원 기출 문항을 그대로 옮기면 안 되고(본인 노트 기반으로 재구성), 원작 게임의 이름·아트·UI를 베끼면 안 됨. "태그가 겹치면 이어지는 카드 게임"이라는 **규칙 자체는** 문제되지 않지만 외형은 독자적으로 만들어야 함
- 개인정보처리방침 URL, 스크린샷, 연령 등급 설문 등 메타데이터 준비

→ 먼저 PWA로 만들어 몇 주 써 보고, 동기들 반응이 좋으면 그때 같은 코드를 Capacitor로 감싸 앱스토어에 내는 순서가 효율적입니다 (이 코드는 거의 그대로 재사용 가능).

### 단축어로는 어디까지?
- 가능: "목록에서 선택"으로 **4지선다 연관어 퀴즈**, 사전(Dictionary) 동작에 카드 데이터 저장, 매일 알림으로 1문제 출제
- 불가능: 카드 배치·탭·애니메이션 같은 **게임 화면** — 단축어는 메뉴와 알림창만 띄울 수 있음
- 현실적 활용: 단축어는 **이 웹 앱을 여는 런처**나 **자투리 시간 한 문제 퀴즈**로 보조 역할
